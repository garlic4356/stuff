Connexions (identifiants & TOTP)

Les connexions donnent à l'agent ses identifiants (login, mot de passe, code TOTP) pour consulter les sources exigeant une connexion. Les valeurs ne sont jamais affichées ici : une connexion enregistrée ne peut être modifiée que par remplacement. Un champ laissé vide conserve la valeur enregistrée ; un nom jamais enregistré crée une connexion. Collez le secret TOTP exactement tel que fourni (URI otpauth:// ou code base32).

Navigateur de l'agent

« Réinitialiser » ferme le navigateur de l'agent (s'il tourne) et efface son profil : toutes les sessions enregistrées (connexions aux sites) sont déconnectées. Les identifiants stockés dans les connexions ci-dessus sont conservés. Le profil se recrée à la prochaine navigation de l'agent.

Mémoire de l'agent

L'agent note ici ses recettes de recherche et les particularités des fiches ; il les consulte au début de chaque mise à jour. Modifier une note change seulement son texte (l'ancien reste dans l'historique de la note) ; pour la renommer, créez une nouvelle note puis oubliez l'ancienne. Les notes oubliées sont archivées, pas détruites. Texte limité à 500 caractères.

⚠️ Site de consultation : vérifiez auprès des organisateurs avant de vous déplacer (inscriptions, tarifs, accès, horaires).
